# Planches des 3 design systems

Propositions d'origine (2026-10-04) qui ont servi à construire `docs/DESIGN.md`. Les trois thèmes sont en production depuis la v3.2.0, au choix du joueur.

| Planche | Thème | Identifiant |
|---|---|---|
| [A · Tapis de jeu](a-tapis-de-jeu.png) | Défaut, clair + sombre | `tapis` |
| [B · Soirée néon](b-soiree-neon.png) | Sombre seulement | `neon` |
| [C · Confettis](c-confettis.png) | Clair + sombre | `confettis` |

Les fichiers `.html` sont les sources des planches (ouvrir dans un navigateur, polices chargées depuis Google Fonts, à usage de maquette uniquement).

## Écarts entre les planches et la version finale
La référence est `docs/DESIGN.md`. Par rapport aux planches :
- nom : « Skyjo d'Olivier » (et non « Les cartes d'Olivier »), 2 à 4 joueurs (et non 8) ;
- Soirée néon : Outfit au lieu d'Inter, bouton principal en aplat (pas de dégradé) ;
- Tapis de jeu : texte des boutons tomate en encre (contraste AA) ; Confettis : chiffre ardoise sur les cartes jade, dos des cartes ardoise (et non bleu) ;
- polices auto-hébergées en production ; plateau mobile avec les adversaires sur une rangée en haut.
